## 💡 일하는 방식

- 기술부터 선택하기보다 **사용자가 겪는 문제와 업무 흐름을 먼저 정의**합니다.
- 정상 흐름뿐 아니라 **실패·예외 상황과 복구 방식**까지 함께 설계합니다.
- 중요한 작업은 AI가 바로 실행하기보다 **Human-in-the-loop와 사용자 승인 과정**을 고려합니다.
- 서로 다른 데이터를 서비스에서 사용할 수 있도록 구조화하고 연결하는 과정에 관심이 많습니다.
- 팀 프로젝트에서는 요구사항과 우선순위를 정리하고 전체 서비스 흐름을 연결하는 역할을 주로 맡았습니다.
